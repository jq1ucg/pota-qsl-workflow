# ftx1-remote

FTX-1 の CW メッセージ / ボイスメモリー再生を、PC なしで FH-2 から操作する
ESP32-S3 製リモコン。FH-2 (抵抗ラダー式キーパッド) の押下を ESP32-S3 が読み、
USB ホストとして FTX-1 の CAT-1 (Enhanced COM Port) へ CAT コマンドを送る。

> **状態: 設計 + 未検証スケッチ。** コンパイルも実機試験も未実施。
> 下の「検証手順」で、特に ★ を付けた項目を最初に確認すること。

マスター資料: `FTX-1_CAT_OM_JPN_2512-D.pdf` (CAT Operation Reference Manual)
および FH-2 リモート回路図 (KEY1-12 の電圧/抵抗表)。

## 1. 機能

| FH-2 キー | 動作 | 送出 CAT |
|---|---|---|
| KEY 1〜5 (CW バンク) | CW メッセージ ch1〜5 再生 | `KY11;`〜`KY15;` |
| KEY 1〜5 (SSB バンク) | ボイスメモリー CH1〜5 再生 | `PB01;`〜`PB05;` |
| KEY 6 (MEM, 4120Ω) | バンク切替 CW ⇄ SSB (LED 表示) | (内部のみ) |
| KEY 12 (DEC, 25550Ω) | 再生停止 | `KY10;` + `PB00;` |
| KEY 7〜11 | 未使用 | — |

- 起動時は CW バンク。FTX-1 切断中の押下は送信せずログのみ。
- コマンドは必ず `;` 終端。エラー応答 `?;` は USB 受信ログに出る。
- CAT-2 (Standard COM) は PTT/KEY 制御用なので使わない。DTR/RTS も操作しない
  (誤送信防止。マニュアルの RPTT SELECT / PC KEYING の注意に対応)。

## 2. ハードウェア構成

```
 [モバイルバッテリー]──USB-C──▶ ESP32-S3 DevKitC-1 の「UART」側 USB-C (給電のみ)
                                   │5V ピン ─── 0.5A ポリヒューズ ─── USB-A メス VBUS(1)
                                   │GPIO19 (USB_D-) ───────────────── USB-A メス D-(2)
                                   │GPIO20 (USB_D+) ───────────────── USB-A メス D+(3)
                                   │GND ──────────────────────────── USB-A メス GND(4)
                                   │                                         │
                                   │                          USB-A(オス)⇄USB-C(オス) ケーブル
                                   │                                         │
                                   │                                   FTX-1 側面 USB-C
                                   │
 FH-2 ──3.5mm プラグ── 3.5mm ジャック            3V3 ──[4.7kΩ 1%]──┬── GPIO4 (ADC1_CH3)
        (先端=OUT, 根元=GND)  先端 ───────────────────────────────┤
                              根元 ── GND                       [100nF]── GND

 LED: GPIO6 ─[1kΩ]─▶|─ GND (CW バンク)   GPIO7 ─[1kΩ]─▶|─ GND (SSB バンク)
```

### 部品表 (概算)

| 部品 | 数量 | 備考 |
|---|---|---|
| ESP32-S3-DevKitC-1 (N8 など) | 1 | USB-OTG ピン GPIO19/20 を使う |
| USB-A メス ブレークアウト | 1 | ホスト側コネクタ |
| USB-A オス ⇄ USB-C オス ケーブル | 1 | **A–C ケーブルを使う理由は下記** |
| 抵抗 4.7kΩ 1% | 1 | プルアップ (FTX-1 側の FH-2 入力と同じ値) |
| コンデンサ 100nF | 1 | ADC 入力のノイズ低減 |
| 3.5mm ジャック | 1 | FH-2 プラグ用 (2 極でも 3 極でも可) |
| ポリヒューズ 0.5A (またはダイオード) | 1 | VBUS 保護 |
| LED + 1kΩ | 2 | バンク表示 (省略可) |
| モバイルバッテリー | 1 | 常時給電モード付きが望ましい |

### 設計上の理由

- **USB-A メス + A–C ケーブル**: C–C ケーブルは、両端の機器が CC ピンで役割
  (ホスト/デバイス) を決める。DevKit の USB-C は「デバイス側」の抵抗 (Rd) を持ち、
  FTX-1 もデバイス側と考えられる。A–C ケーブルは内部に電源側の抵抗 (Rp 56kΩ) を持つので、
  ESP32 を確実にホストとして接続できる。
- **VBUS は ESP32 側から出す**: FTX-1 の USB-C が 5V を出すかは未確認。
  出ないものとして、バッテリーの 5V を VBUS に供給する。デバイス側が VBUS 検出で
  接続する機器でも動くようにするため。
- **FH-2 入力**: 無線機側と同じ 4.7kΩ プルアップ (5V→3.3V)。電圧は 0.66 倍になるだけで、
  キーの並びは FH-2 の表と同じ。しきい値はスケッチが 4.7kΩ とキー抵抗から自動計算する。

| キー | 抵抗 | 期待電圧 (3.3V 系) | 判定範囲 |
|---|---|---|---|
| 1 | 866Ω | 0.51V | 〜0.62V |
| 2 | 1330Ω | 0.73V | 〜0.83V |
| 3 | 1820Ω | 0.92V | 〜1.03V |
| 4 | 2490Ω | 1.14V | 〜1.25V |
| 5 | 3240Ω | 1.35V | 〜1.45V |
| 6 (MEM) | 4120Ω | 1.54V | 〜1.65V |
| 7〜11 | 5360〜16900Ω | 1.76〜2.58V | 未使用 |
| 12 (DEC) | 25550Ω | 2.79V | 〜3.0V |
| 無押下 | — | 3.3V | 3.0V 以上 |

### 電源

- バッテリーから DevKit の UART 側 USB-C に給電する。ESP32 は常時約 100mA 未満の想定。
- 低電流で自動停止するモバイルバッテリーは避ける (常時給電/低電流モード付きを選ぶ)。
- 5V ピンから VBUS へ流す電流は小さい (FTX-1 が自前電源なら数 mA〜数十 mA)。

## 3. ビルド

ESP-IDF 5.2 以上 (ESP32-S3)。

```
cd ftx1-remote
idf.py set-target esp32s3
idf.py build flash monitor     # UART 側 USB-C で書き込み・ログ確認
```

`espressif/usb_host_cp210x_vcp` はコンポーネントマネージャが取得する。
GPIO19/20 は USB ホスト専用にするので、ログ/書き込みは UART 側 USB-C を使う。

## 4. 検証手順 (実機)

1. ★ **FTX-1 の USB-C の VBUS 電圧**: テスターで確認。5V が出るなら
   給電の見直し(別電源不要)も可。出なければ現行設計のまま。
2. ★ **CP210x のインターフェース番号**: FTX-1 は「Dual CP210x」(CP2105 想定) で
   2 ポートが見える。`main.c` の `CAT_INTERFACE_IDX` (既定 0 = Enhanced = CAT-1 と想定) で
   接続し、起動時に送る `FA;` に `FA…;` が返るか RX ログで確認。
   返らなければ `1` に変更する。
3. ★ **cp210x_vcp_open の API / CP2105 対応**: コンポーネントのバージョンで
   関数名・引数が違う場合は `main.c` を合わせる。CP2105 の 2 ポートを開けない場合は
   別実装 (ベンダ要求の自前制御) か、CAT-3 (TUNER/LINEAR 端子, 5V CMOS UART) 案に切替。
4. **FH-2 の抵抗実測**: `DEBUG_PRINT_MV` を 1 にして押下時の mV を記録し、
   上の表と比較。特に KEY1〜6 と 12。ずれが大きければ `KEY_OHM[]` を実測値に置換。
5. **CAT 動作**: CW バンクで KEY1 → `KY11;`、SSB バンクで KEY1 → `PB01;`。
   ★ **再生が自動で送信になるか**を、ダミーロードで必ず確認 (マニュアルに明記なし)。
   送信にならない場合は `TX1;` / `MX1;` の併用を検討する。
6. **停止**: 再生中に KEY12 で止まるか (`KY10;` / `PB00;`)。再生中に別キーを押したときの挙動も記録。

## 5. 既知の未確定事項

- FTX-1 に FH-2 用 REMOTE 端子があるかは不明。本機は FH-2 の抵抗値を自前で読むので不要。
- FH-2 のプラグ径 (3.5mm 2 極) は取扱説明書の記述。実物で確認すること。
- クローン回路にある SW13 + 22nF の用途は不明 (本機では使わない)。
